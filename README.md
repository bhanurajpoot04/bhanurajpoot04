## 🚀 Featured projects

| Project | What it does | Built with |
|---|---|---|
| **SCARA Robotic Arm** | 3D-printed 4 DOF arm for pick-and-place of small objects, controlled by hand gestures tracked from a camera. Team project with Parth Marotkar and Bhavya Pahadiya, presented at NLPC-26. | Python, OpenCV, stepper motors, servo gripper |
| **Colour & Shape Sorting Conveyor** | Sorts objects on a belt using computer vision. Passes green items and diverts red ones through a servo gate. Custom PCB. | Raspberry Pi 5, OpenCV, Pi Camera, L298N |
| **Smart Hydroponics System** | Monitors pH, TDS, temperature and humidity, and runs 230V and 12V pumps on a schedule. Custom PCB. | ESP32, DS3231 RTC, relays, I²C |
| **Toroid Coil Winding Machine** | Automates copper wire winding on toroidal cores with live turn counting on an LCD. Custom PCB. | Arduino Nano, NEMA 17 + A4988, L293D, IR sensor |
| **Weather Monitoring & Control System** | IoT weather station reporting temperature and humidity over Wi-Fi, with an on-site LCD and automated control. | ESP, Wi-Fi, sensors, LCD |
| **STM32 LCD Interfacing** | Displays text on a 16×2 LCD from an STM32 (first project after LED blink with buzzer, from my STM32 training). | STM32F103C8T6, STM32CubeIDE, Embedded C, GPIO |

> Detailed code, circuit diagrams, PCB files and photos for each project are being added to my repositories.
